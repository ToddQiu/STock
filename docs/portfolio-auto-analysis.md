# 持仓组合的自动计算

“组合分析”使用本地确定性算法，不调用大模型，也不需要 AI API Key。公开行情源负责提供价格和复权历史；AI 个股报告、AI 组合研判仍是独立功能。

## 更新方式

- 软件运行时，后台每 30 秒检查全部组合，依次为新组合或新增标的补齐分析资料。打开组合或切换统计年份也会触发检查。
- 已取得的历史资料每 30 分钟自动更新；资料采集失败时约 5 分钟后重试，同时遵守行情源限流冷却。成功的历史保留原始采集时间，不用失败或空结果覆盖。
- 工作台每 10 秒读取最新持仓估值。持仓数量、市值、现金、应收、应付变化后，仓位、集中度、配置诊断和结构模拟随之重算，无须再次生成 AI 分析。
- “更新分析”主动更新持仓行情、年度与近期历史，完成后自动显示新结果。切换组合或年份不会接收前一次选择的迟到响应。
- 相关性、历史回撤、年化波动使用已完成的收盘数据，未收盘的日线不作为最终收益区间。历史不变时这些指标不会为了显示“实时”而任意变化。

## 固定公式

全部金额先按已有汇率口径换算成组合计价币种。记证券市值为 `V_i`，库存现金为 `C`，应收为 `R`，应付为 `L`。

| 指标 | 计算方式 |
| --- | --- |
| 总资产 | `T = ΣV_i + C + R − L`，沿用用户确认的应付扣除口径 |
| 单标的仓位 | `V_i / T × 100%`；选择证券市值口径时，分母改为 `ΣV_i` |
| 前五大持仓 | 按同一证券归并后，最大五项市值之和除以所选分母 |
| 现金占比 | `C / T × 100%`；应收不作为现金 |
| 模拟净值 | `N_t = (C + R − L) / T + Σ[(V_i / T) × P_i,t / P_i,0]`，`P` 为来源提供的复权收盘价 |
| 模拟收益 | `(N_end / N_start − 1) × 100%` |
| 最大回撤 | `min[N_t / max(N_0…N_t) − 1] × 100%` |
| 年化波动 | 净值相邻共同收盘日收益的样本标准差 `× √252 × 100%`，至少 20 个区间 |
| 年度相关性 | 同起止日期的两个证券复权收益序列计算 Pearson 系数；每对至少 20 个区间 |
| 平均相关性 | 所有有效、不重复证券配对的系数等权平均，不含对角线 |
| 近期相关性 | 最近 60 / 120 个可对齐区间，至少 20 / 40 个样本；延续原有异常大幅变动区间过滤规则 |
| 集中度提醒 | 将单仓、前五大、行业权重与账户中保存的上限比较 |
| ETF 穿透 | 当前 ETF 市值乘已披露底仓权重，按底层证券标识合并重复敞口，保留披露期末和覆盖缺口 |

结构模拟以当前配置权重在历史起点一次建仓、买入持有，现金、应收、应付及汇率固定，不含交易费用。它用于检验当前持仓结构，并非包含真实交易和出入金的账户收益。

## 不足数据的处理

完整年度优先采用选年前最后一个共同有效收盘作为起点。若存在上市较晚或年初历史不足的标的，使用全部持仓都具有复权价格的年内共同区间，并显示“共同区间模拟收益”和真实起止日期。不会剔除缺价持仓来凑出一个完整组合，也不会将共同区间冒充全年。

没有足够共同历史、缺少复权口径、币种不符或估值汇率缺失时，对应指标保持缺失，并在“设置与来源”列出原因。真实零值仍按零显示。PDF 和 Excel 使用同一计算引擎与字段口径。

## 本次验证

- 自动启动、失败重试、持仓范围变化、历史年份切换和三个组合隔离均有回归测试。
- 本地公式与界面测试覆盖价格权重、现金变化、新上市共同区间及迟到响应。
- 本机成都、温州、Todd 分别自动取得 6、15、7 个标的的历史；有效年度配对分别为 15、105、21 对。温州采用 2026-01-08 至 2026-11-13 的共同区间。
- 验证前后账户配置文件校验值一致。公开行情可用性仍取决于来源，受限时自动重试并显示缺项。
