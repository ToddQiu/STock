# STock 待上线包

这不是已经上线的网站。当前不购买服务器、不付费、不申请付费 API。

## 资金到位后，只准备这四项

1. 一台专用的 Ubuntu 24.04 x86-64 云服务器。此前核对的香港 4 核 8GB、70GB 套餐首月为 224 元，关闭自动续费；这是 2026-10-16 报价，购买时必须重新确认。不要在已有其他业务的服务器盲目运行安装脚本。
2. 一个你能修改 DNS 的域名或子域名。A 记录指向服务器公网 IPv4，删除指向其他地址的 A/AAAA 记录；先关闭 CDN 代理，使用直连 DNS。本方案不自动购买域名，也不沿用尚未核验的旧域名。
3. 阿里云防火墙允许公网 TCP 80/443；SSH 22 仅允许你的管理 IP。不要开放 8080、数据库端口或 Docker 管理端口。
4. SSH 密钥登录可用，并在阿里云控制台核对服务器主机密钥指纹后，完成首次 SSH 连接。脚本强制检查指纹，不会自动信任陌生主机，不收集密码。非 root 用户需要可用的非交互 sudo。

## 一次运行

解压整个上线包，双击 `Launch-STock.cmd`，填写 `用户名@公网IPv4` 和域名。使用指定密钥或自定义端口时，在该文件夹打开 PowerShell：

```powershell
.\Launch-STock.ps1 -Server root@你的公网IP -Domain 你的域名 -Port 22 -IdentityFile 你的SSH私钥文件路径
```

执行策略禁止脚本时，先查看脚本内容并按本机组织策略处理；包内不会自动关闭执行策略。

入口会核对压缩包 SHA256、SSH、DNS，安装官方 Docker，构建完整后台与翻译模型，生成只保存在服务器的随机访问密码，启动 HTTPS，并检查认证、完整页面和 12 个 API。首次构建需要联网下载依赖和模型，可能持续十几分钟以上。

用户名为 `stock`。密码仅在服务器 `/opt/stock/access-key.txt`，不会显示在自动化日志、写进 GitHub 或放进 URL。通过已验证的 SSH 私下读取，网址和密码分开发给朋友。

**当前是受邀共享工作区：同一密码的朋友可以看、改、导出同一份持仓与研究。不要导入私人数据。这不是每人独立账户。** 桌面私人数据库不会打包，云端首次启动为空持仓、零本金。

Windows 系统弹窗不属于网站功能；网页保留事件中心。免费上游源可能限流或失败，需要授权的来源仍需合法授权。规则评分不是上涨概率，未接模型 API 时不会伪装成已启用模型分析。

## 上线后的日常命令

以下命令在上线包所在文件夹执行；`-IdentityFile` 和 `-Port` 可照首次启动补充。

```powershell
.\Launch-STock.ps1 -Server root@你的公网IP -Action status
.\Launch-STock.ps1 -Server root@你的公网IP -Action verify
.\Launch-STock.ps1 -Server root@你的公网IP -Action backup
.\Launch-STock.ps1 -Server root@你的公网IP -Action rollback
```

- 升级：使用新生成且已测试的上线包再次运行。先构建，再暂停应用做一致性备份。成功后保留旧镜像与旧版本；同版本重复运行不会清空工作区或更换密码。
- 回退：恢复升级前的备份到新数据卷，再启动旧镜像。**升级后的修改不进入旧备份，但失败版本的数据卷保留供恢复**。回退前先备份最新数据；首次部署没有旧版本可回退。
- 备份：存放在 `/opt/stock/backups/`，与数据同机，不等于异地备份。通过已验证 SSH 将整个 `/opt/stock` 管理目录、访问密码和备份下载到安全位置；不要上传公共仓库。服务器丢失后须用对应版本和备份重建，HTTPS 证书可重新签发。
- 脚本不删除历史卷、备份或镜像。定期检查磁盘，空间不足时部署会停止，需要核对后清理，不会擅自删数据。
- 服务器到期后网站会停。自动续费保持关闭，由你手动决定是否续费。
