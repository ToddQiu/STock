STock 桌面分享版 | Windows x64

使用方法
1. 双击 STock-Setup 安装程序，按提示安装；无需管理员权限。
2. 使用桌面或开始菜单的 STock 入口。若使用 ZIP 版，完整解压后运行 STock.exe，保留其同目录文件。
3. 首次启动没有历史数据，联网后逐步采集。后续启动会读取本机保存的数据。

此包内置桌面窗口、Python 后台和本机英译中模型，无需安装 Python、Node 或开发工具。
适用于 Windows 10/11 64 位。不是微信小程序安装包，也不是 macOS 版本。
程序没有商业代码签名，Windows 可能显示“未知发布者”。请确认文件来源可信，勿关闭系统安全防护。

个人数据
分享包不含制作者的持仓、本金、研究记录、登录状态、密钥、缓存或私有配置。
初始观察名单是公开的示例公司，不代表持仓或投资推荐。
持仓、研究记录、设置和缓存保存在 %APPDATA%\STock，可按 Win+R 输入该路径查看。
更新前关闭 STock，再运行新版安装程序。卸载仅移除程序文件，个人数据保留在上述目录。不要将该数据目录转发给别人。
同一 Windows 用户只运行一个分享版窗口。关闭窗口后，其本地采集后台也会退出。

联网与分析
行情和新闻需要联网。来源可能限流、延迟、休市或在所在网络无法访问；以页面的数据时间、状态和原文为准。
本地分析默认使用规则引擎，不包含任何付费 API 账号或额度，不会自动交易。
英文新闻保留原文，并在下方逐条生成中文机器翻译。首轮加载模型、翻译较多新闻需要时间。
机器翻译和情绪判断都可能出错，重要事实应核对原始来源；分数不是经过校准的上涨概率。
需要登录或授权的社交平台，不会因为有此运行包而自动获得访问权限。
研究页保留功能和公开公司目录，但不附带制作者私人研究库、历史导入文件或个人 ETF 快照。

排错
启动失败可查看 %APPDATA%\STock\desktop-service.log。
请先确认已经完整解压、磁盘空间足够，并查看 Windows 安全中心是否隔离了文件。
不需开放公网端口，内置服务只监听本机 127.0.0.1 的自动分配端口。
软件仅供研究参考，不构成投资建议或收益承诺。
